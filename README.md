# Enlace · Apuntes completos de redes

Web estática en español publicada en GitHub Pages.

## Alcance

- CAPA I: programa completo del primer documento, páginas 1–110.
- CAPA II: exclusivamente páginas 1–72 del segundo documento, sin CAPA III.
- 15 temas y 61 apartados redactados con palabras propias, con mapa de cobertura sin huecos ni solapamientos.
- Resumen completo en una pestaña propia (`resumen.html`), impresión y descarga en PDF y Markdown.
- 109 preguntas explicadas, con acceso al apunte correspondiente, filtros por capa/tema y prácticas de 15, 30 o todas las preguntas disponibles.
- Las prácticas breves distribuyen preguntas entre los temas del filtro. La práctica completa contiene preguntas de cada apartado.
- Se retiraron las diapositivas originales de la versión actual; los apuntes no incluyen fotografías, capturas, texto extraído ni nombre del docente.

## Fuentes

`sources.js` distingue libros abiertos consultados, recursos oficiales de autores, bibliografía editorial y comprobaciones técnicas. La ficha de *Computer Networks* de Tanenbaum, Feamster y Wetherall es una referencia bibliográfica, no una afirmación de lectura íntegra. Las ampliaciones y aclaraciones se enlazan a sus fuentes; se conservan como históricas las cifras originales que dependen de la fecha del material. Los detalles ilegibles de imágenes degradadas no se inventan.

## Uso y publicación

Abre `index.html` o ejecuta `python3 -m http.server 8000`. No requiere dependencias ni proceso de compilación. Las fuentes de Google Fonts tienen alternativas locales.

GitHub Actions publica al actualizar `main`. Pages utiliza el origen GitHub Actions. Las imágenes originales no se incluyen en el artefacto actual. Como en cualquier repositorio Git, las versiones anteriores siguen formando parte de su historial.

El progreso y resultados se guardan mediante localStorage del navegador, sin sincronización ni recopilación en servidor. Las preguntas son material de práctica, no preguntas oficiales.
